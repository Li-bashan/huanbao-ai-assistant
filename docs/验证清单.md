# 验证清单

更新时间：2026-07-22

每次修改后至少执行 `npm run build`。Dify、iGIX 用户和窗口协议需要在真实门户环境完成最终验收。

## 1. 构建与基础页面

```bash
npm install
npm run build
npm run dev -- --host 127.0.0.1
```

- 构建无错误。
- `http://127.0.0.1:5173/` 返回 200。
- 独立访问时 iGIX 用户/窗口服务不可用只输出降级日志，页面不崩溃。

- 自动路由到制度问答。

## 4. 流程助手

### 采购请示单

输入：`打开采购请示单`

- 自动路由到流程助手并展示动作卡片。
- 点击前不发送消息；点击一次后只调用一次 bridge。
- 控制台仅出现一次 `IGIX ACTION SEND`。
- 消息结构为 `type = IGIX_AI_ACTION`。
- `payload.action = open_form`。
- `payload.formCode = CGQSD`。
- `payload.funcId = 9744034a-7fcc-4510-97fa-f563aecd26e6`。
- `payload.actionId` 存在且每次发送唯一。
- payload 不包含 `fields`，不自动提交。
- 不出现 `DataCloneError` / `could not be cloned`。
- iGIX 父页面按 `actionId` 去重，只打开一个表单。

### 待实测和不支持入口

- `打开采购请示单台账`：显示 `pending`，不显示执行按钮，不发送动作。
- `打开检修项目立项备案审批`：显示 `pending`，不发送动作。
- `打开议案汇总清单审批`：显示 `unsupported`，不发送动作。
- `打开不存在的流程`：提示补充具体名称，不展示假按钮。

### 流程清单

输入：`运维模块都有什么流程可以发起`

- 按模块列出配置入口和状态。
- 提示“实际可办理权限以 iGIX 权限为准”。
- 不假装已做真实权限过滤。

## 5. 标题栏与窗口

在真实门户 iframe 中验证：

- 新对话清空当前对话并正确保存有效历史。
- 历史弹层在小窗内完整显示，不被左右裁切。
- 小窗显示放大到中窗图标；点击后父页面进入 `wide`。
- 中窗显示缩小到小窗图标；点击后父页面进入 `compact`。
- 非全屏显示全屏图标。
- 全屏隐藏中窗和全屏按钮，只显示直接返回小窗图标及关闭图标。
- 关闭按钮发送 `close`；Esc 发送 `escape`。
- 父页面回传状态后，图标与实际窗口状态一致。
