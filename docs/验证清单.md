# 验证清单

每次修改后至少执行 `npm run build`，涉及功能时按以下项目人工验证。

## 1. 制度问答验证

输入：

```text
差旅费包括哪些费用？
```

预期：

- 自动进入制度问答。
- 返回制度答案。
- Markdown 正常。
- 展示引用来源。
- 可展开原文片段。

## 2. 办公智能验证

输入：

```text
帮我写一份关于智慧办公系统临时维护的通知
```

预期：

- 自动进入办公智能。
- streaming 输出。
- 不显示 `<think>`。
- 最终内容可复制和导出。

## 3. 流程助手验证

输入：

```text
打开采购请示单
```

预期：

- 自动进入流程助手。
- 展示动作卡片。
- 点击按钮追加演示提示。

## 4. 意图识别验证

输入：

```text
给我整理会议纪要：流程、表单、审批节点……
```

预期：

- 进入办公智能。
- 不误判为流程助手。

## 5. 历史记录验证

- 历史可搜索。
- 可按制度 / 办公 / 流程筛选。
- 可删除单条。
- 可清空历史。
- 恢复历史后模式和消息正常。

## 6. 复制导出验证

- AI 回复可复制。
- 可导出 Markdown。
- 可导出 Word/HTML。
- 流程动作卡片导出内容包含事项、操作和字段。

## 7. 构建验证

```bash
npm run build
```

预期：构建通过。
