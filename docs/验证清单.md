## 2. 真实门户必须补测

### 制度问答

输入“差旅费包括哪些费用？”。确认自动路由、blocking 完整返回、引用来源可见且不伪造来源。当前工作区主路径是 /api/ai/master/chat，兼容 policy 路由仍需分别确认是否保留。

### 办公智能

输入“帮我写一份关于智慧办公系统临时维护的通知”。确认 SSE 实时更新、过滤 think、最终可复制和导出。再用“给我整理会议纪要：流程、表单、审批节点……”确认不会误判为流程助手。

### 智能问数

使用真实门户登录用户完成 access、首轮查询、澄清、会话续问、v2 结构化结果、图表、证据和 follow-up。核对 Gateway Key 对应的 Dify App/发布版本，确认 Dify 消费 auth_context_json 和组织范围；再用测试库核对 SQL、表字段、超时、行数上限和审计落库。

### 流程助手

确认采购请示单在真实父页面打开；确认 parent 收到 IGIX_AI_ACTION 后只执行一次。补测 pending、unsupported 和不存在入口不展示假按钮。确认窗口控制 close、escape、compact、wide、fullscreen 与父页面状态同步。
