# 验证清单

每次修改后至少执行 `npm run build`，涉及功能时按以下项目人工验证。

## 1. 制度问答验证

输入：

```text
差旅费包括哪些费用？
```

预期：

- 自动进入制度问答。
- 返回制度答案。
- Markdown 正常。
- 展示引用来源。
- 可展开原文片段。

## 2. 办公智能验证

输入：

```text
帮我写一份关于智慧办公系统临时维护的通知
```

预期：

- 自动进入办公智能。
- streaming 输出。
- 不显示 `<think>`。
- 最终内容可复制和导出。

## 3. 流程助手验证

### 3.1 打开采购请示单

输入：

```text
打开采购请示单
```

预期：

- 自动进入流程助手。
- 展示动作卡片。
- 点击“打开采购请示单”后发送 `IGIX_AI_ACTION`。
- `payload.action = "open_form"`。
- `payload.formCode = "CGQSD"`。
- `payload.funcId = "9744034a-7fcc-4510-97fa-f563aecd26e6"`。
- payload 自动带 `actionId`。

### 3.2 采购请示单不发送 fields

输入：

```text
帮我发起一个采购请示单，项目名称办公电脑采购，联系人张三，预算50000
```

预期：

- 展示采购请示单动作卡片。
- 不显示“帮我预填表单”按钮。
- 点击“打开采购请示单”后发送 `IGIX_AI_ACTION`。
- `payload.action = "open_form"`。
- payload 不包含 `fields`。
- 不自动填表。
- 不自动提交表单。
- 不出现 `DataCloneError`。

### 3.3 查询运维模块可发起流程

输入：

```text
运维模块都有什么流程可以发起
```

预期：

- 不要求用户补充具体表单名。
- 返回运维模块下已配置流程入口。
- 每个入口展示业务名称、可执行状态和简短说明。
- 状态应区分“已开放 / 待实测 / 暂不支持”。
- 必须提示“当前展示的是已配置入口状态，实际可办理权限以 iGIX 权限为准。”

### 3.4 查询我的权限可发起流程

输入：

```text
我的权限都可以发起什么流程
```

预期：

- 明确提示“当前展示的是已配置入口状态，实际可办理权限以 iGIX 权限为准。”
- 展示当前已配置流程入口。
- 不假装已经做了真实权限过滤。
- 状态应区分“已开放 / 待实测 / 暂不支持”。

### 3.5 打开采购请示单台账

输入：

```text
打开采购请示单台账
```

预期：

- 展示采购请示单台账动作卡片。
- 该入口当前为 `pending`。
- 不展示可点击执行按钮。
- 不发送 `IGIX_AI_ACTION`。
- 页面提示“待实测，暂未开放”。

### 3.6 打开检修项目立项备案审批

输入：

```text
打开检修项目立项备案审批
```

预期：

- 展示检修项目立项（备案）审批动作卡片。
- 该入口当前为 `pending`。
- 不展示可点击执行按钮。
- 不发送 `IGIX_AI_ACTION`。
- 页面提示“待实测，暂未开放”。

### 3.7 打开议案汇总清单审批

输入：

```text
打开议案汇总清单审批
```

预期：

- 该事项为 `open_related`。
- 不展示可点击打开按钮。
- 不发送 `IGIX_AI_ACTION`。
- 页面提示“不支持直接打开”。

### 3.8 未配置流程提示

输入：

```text
打开不存在的流程
```

预期：

- 不发送 `IGIX_AI_ACTION`。
- 提示用户补充具体表单或流程名称。
- 不展示假按钮。
