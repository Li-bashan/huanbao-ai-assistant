# 开发任务记录

更新时间：2026-07-22

本文档用于记录后续功能迭代。

## 已完成功能

- 企业门户右侧助手 UI。
- 环宝 AI 视觉风格。
- 制度问答 Dify blocking。
- 办公智能 Dify streaming。
- `<think>` 过滤。
- Markdown 渲染。
- 引用来源展示和展开。
- 流程助手模式。
- 流程助手动作卡片。
- 流程入口清单查询。
- 流程入口按采购模块、运维模块、科技模块、综合模块分组展示。
- 采购请示单打开 iGIX 最小闭环。
- 企业级试点上线模式：字段预填关闭，只打开表单 / 菜单。
- iGIX 入口状态治理：`verified` / `pending` / `unsupported`。
- `open_form` / `open_menu` 动作发送。
- `open_related` 暂不执行。
- 未配置事项不展示假按钮。
- `actionBridge` 统一发送 `IGIX_AI_ACTION`。
- `actionId` 动作标识。
- payload 清洗，避免 Vue Proxy 导致 `DataCloneError`。
- 自动意图识别。
- localStorage 历史记录。
- 历史搜索、筛选、删除、清空。
- 复制、导出 Markdown、导出 Word/HTML。
- Nginx 静态部署。
- 标题栏右侧操作改用 `@lucide/vue` 图标。
- 接入 `IGIX_ASSISTANT_WINDOW` / `IGIX_ASSISTANT_WINDOW_STATE` 窗口协议。
- 支持小窗、中窗、全屏、直接返回小窗和关闭。
- 修复小窗历史弹层被裁切及中窗缩放图标状态错误。
- 移除标题栏模式切换，保留自动意图路由。

## 当前版本状态

当前版本为 V1：可演示、可使用的企业门户 AI 助手前端。制度问答和办公智能已接真实 Dify，流程助手按企业级试点上线版收口，只开放已验证入口，不发送字段，不自动填表，不自动提交。

## 流程助手当前阶段

### 已完成

- 支持具体流程入口识别，例如“打开采购请示单”“打开采购请示单台账”。
- 支持宽泛流程清单查询，例如“运维模块都有什么流程可以发起”“我的权限都可以发起什么流程”。
- 支持按业务模块展示当前已配置入口。
- 支持采购请示单打开。
- 通用性备案表等 `pending` 入口可识别但不可执行。
- 合同评审等未配置事项只提示补充具体名称，不展示假卡片。
- 支持 `open_form`、`open_menu` 动作发送。
- 对 `open_related` 保持不可执行状态。
- `pending`、`unsupported` 或缺少 `formCode` / `funcId` 的事项不展示可点击动作按钮。
- 流程清单按模块和状态展示：已开放、待实测、暂不支持。
- 开发环境 actionBridge 日志包含 `actionId`、`action`、`formCode`、`funcId`、`status`、`hasFields`、`sentAt`。

### 当前不做

- 不接 Dify candidates。
- 不发送 `fields`。
- 不做字段预填。
- 不自动提交表单。
- 不做真实权限过滤。
- 不处理下拉、日期、参照控件、附件等复杂字段。
- 不执行联查类入口。
- 不绕过 iGIX 权限校验。

- 字段预填已关闭，后续如重新启用必须单独立项和验收。
- `open_related` 入口协议未确认，不能直接发送动作。
