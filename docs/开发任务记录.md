# 开发任务记录

更新时间：2026-09-02

本文记录当前已经具备的能力、仍在进行的工作和下一步验收，不把历史设计或 Dify 交付报告当成生产证据。

## 已具备

- 企业门户右侧助手 UI、四项能力选择器和自动意图路由。
- 制度问答 blocking 兼容代理、办公智能 streaming 兼容代理。
- 已提交统一 Master Gateway SSE 路径；生产服务器部署和 Dify 绑定仍待确认。
- 智能问数 Gateway access、签名身份、授权范围、会话、v2 结果和 SSE 适配。
- 流程助手动作卡片、入口状态治理、采购请示单 verified 闭环。
- actionBridge 清洗 Vue Proxy，生成 actionId，通过配置或来源解析的 origin 发送 IGIX_AI_ACTION。
- localStorage 历史搜索、四能力筛选、恢复、删除、清空。
- 复制、Markdown 导出和 Word/HTML 导出。
- 小窗、中窗、全屏、关闭和门户窗口状态协议。
- Gateway 健康、Dify 代理、问数人员管理、动作校验和审计接口代码。

## 本次验证

- npm run build 通过。
- ai-gateway mvn clean test -q 通过。
- 线上 health 返回 UP；未授权用户管理返回 401；空身份问数返回 CURRENT_USER_MISSING。
- 独立浏览器中采购请示单卡片和 IGIX_ACTION_SEND 可复现。

## 当前不做

- 流程助手不调用 Dify candidates，不做真实业务发起，不发送 fields，不自动填表或提交。
- 不做前端真实权限判断；门户和 Gateway 是权限边界。
- 不把 localStorage 当服务端审计。
- 不假设公式指标、额定参数或 Kingbase 表已经完成实库验收。

1. 在真实门户完成签名身份、问数 access、有效查询、澄清和 v2 结果回归。

5. 逐项实测 pending 入口；确认窗口控制和真实表单打开。

## 风险

- 生产服务器可能尚未拉取或重载最新提交，实际运行链路仍需现场确认。
- Dify 控制台清单、历史文档和 Gateway Key 绑定存在口径差异。
- Dify 直接执行 SQL 时，Gateway 下发 DataScope 是否被工作流严格消费仍需证据。
- action-audits 当前前端不自动写入，代码接口还需要鉴权。
