## 当前工作区状态

当前前端已完成标题栏窗口控制升级，新增 `@lucide/vue` 和 `src/utils/igixAssistantWindow.js`。窗口状态来自门户父页面，不要在 iframe 内自行修改容器尺寸。

当前流程动作已通过 `IGIX_AI_ACTION` 接入父页面。采购请示单为唯一 `verified` 入口；预填开关关闭，其他入口不得擅自改为可执行。

AI Gateway 位于 `ai-gateway/`；当前智能问数开放范围检查已接入网关，制度问答仍直连 Dify。文档中提到网关接口，不代表前端已经完成全量切换。

当前 Dify 实例为 `http://121.237.178.23:9002`。智能问数已发布版本和最新草稿均为 28 节点 / 30 连线，但线上实际仍是已发布版本；两版都由 Dify SQL 插件直接连接 KingbaseES，没有调用 AI Gateway。接手 Dify 相关任务时先阅读[Dify 全部应用与工作流现状](./Dify全部应用与工作流现状.md)。

## 开发检查

```bash
npm install
npm run dev
npm run build
git status
```

开发服务默认地址为 `http://127.0.0.1:5173/`。独立浏览时无法模拟父页面窗口协议和 iGIX 用户服务，相关日志属于预期降级；流程动作和窗口控制必须在门户 iframe 环境完成最终验收。

## 容易误改的地方

- 标题栏展示智能能力选择器，支持四项能力手动切换；自动意图路由继续保留，手动选择不是模式锁。
- 不在 `App.vue` 直接调用 `window.parent.postMessage` 发送流程动作，统一走 `sendIgixAction`。
- 不把 `HUANBAO_AI_ACTION`、`OPEN_FORM` 等旧协议写回代码。
- 不启用字段预填，不自动提交表单。
- `actionId` 由 bridge 注入；父页面需按它去重。
- 不把 loading/streaming 半截消息写入历史。
- 不删除复制、Markdown、Word/HTML 导出。
