## 当前状态

- 前端是 Vue 3 + Vite 右侧 iframe 助手，支持制度、办公、流程、智能问数四项能力。
- 当前代码制度/办公主链路走 /api/ai/master/chat；代码已提交并与 origin/main 同步，生产服务器部署和回归状态仍需确认。
- 智能问数走 /api/ai/data-query/access 和 /api/ai/data-query/chat，生产身份默认由签名头提供。
- 流程助手只有采购请示单 verified；动作通过 actionBridge 发往门户，不发送 fields，不自动提交。
- ENABLE_WORKFLOW_PREFILL=false；智能填单文档是方案，不是当前上线能力。
- 线上 Gateway 健康检查已返回 200 / UP / 0.1.0；无身份问数会被拦截。
- Dify 控制台资产和 Gateway Key 的真实绑定尚未闭环确认。不要用历史 28/30、13/18 或某个 App ID 直接代表当前线上。

## 常用检查

在项目根目录执行 npm run build；在 ai-gateway 目录执行 mvn clean test -q。独立浏览器没有 iGIX 用户和父页面窗口服务，相关降级日志是预期现象；流程动作、窗口控制和有效问数必须在真实门户 iframe 中验收。

## 容易误改

- 不直接在 App.vue 调用 window.parent.postMessage，统一使用 actionBridge。
- 不把旧的 HUANBAO_AI_ACTION、OPEN_FORM 协议写回代码。
- 不把 loading/streaming 半截消息写入历史。
- 不删除复制、Markdown、Word/HTML 导出。
- 不把前端 userContext 当成问数生产权限。
- 不把 Dify 页面可达、Gateway UP 或动作已发送当成业务执行成功。

提交前按 docs/验证清单.md 回归，并确认没有把密钥、HAR 或临时文件加入提交。
