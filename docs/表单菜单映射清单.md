# 表单菜单映射清单

## 文件用途

本文档用于维护流程助手动作卡片与门户 / iGIX 表单、菜单、待办入口之间的映射关系。

## 字段说明

- 业务名称：用户可理解的事项名称。
- id：内部唯一标识。
- formCode：iGIX 表单编码。
- funcId：门户菜单或功能 ID。
- 动作类型：打开表单、打开菜单、查看待办等。
- 是否支持预填：是否可带字段默认值。
- 字段映射：AI 字段与表单字段的映射。
- 必填字段：办理前需要用户补充的信息。
- 示例数据：后续调试用示例。
- 状态：已确认 / 待补充 / 暂不支持。

## 后续维护规则

- 不确定的 `formCode` 和 `funcId` 必须写“待补充”，不要编造。
- 每个映射需由门户 / iGIX 负责人确认。
- 预填字段需要明确字段编码、类型、枚举值。
- 上线前必须做权限校验和审计。

## 字段映射模板

```json
{
  "businessName": "采购请示单",
  "id": "purchase-request",
  "formCode": "待补充",
  "funcId": "待补充",
  "actionType": "OPEN_FORM",
  "prefillSupported": true,
  "fieldMapping": {
    "采购事项名称": "待补充",
    "预算金额": "待补充"
  },
  "requiredFields": ["采购事项名称", "预算金额"],
  "status": "待补充"
}
```
