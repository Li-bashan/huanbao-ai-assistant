# 项目交接说明

更新时间：2026-07-22

## 项目定位

环宝 AI 智能助手是嵌入 iGIX 企业门户的右侧助手前端，提供“查制度、写材料、办流程”三类能力。它不是独立后台，也不负责绕过门户权限直接操作业务系统。

## 当前完成情况

| 模块 | 当前状态 |
|---|---|
| 制度问答 | Dify blocking；支持 Markdown、引用来源和原文片段展开。 |
| 办公智能 | Dify Agent streaming；逐段渲染并过滤 `<think>`。 |
| 流程助手 | 前端规则识别和动作卡片；不接 Dify。 |
| iGIX 动作 | 点击已开放卡片后发送 `IGIX_AI_ACTION`。 |
| 窗口控制 | 标题栏已接入小窗、中窗、全屏、关闭协议。 |
| 历史 | localStorage；搜索、分类筛选、删除、清空。 |
| 内容复用 | 复制、导出 Markdown、导出 Word/HTML。 |
| 当前用户 | 尝试从 iGIX `gspframeworkService` 读取白名单字段，仅用于欢迎语。 |
| AI Gateway | Spring Boot 代码和审计表已加入仓库，前端尚未接入。 |

## 当前流程助手边界

- 当前唯一开放执行的入口是采购请示单：`CGQSD` / `9744034a-7fcc-4510-97fa-f563aecd26e6`。
- 其他已配置入口为 `pending` 或 `unsupported`，只展示状态，不发送动作。
- 字段解析代码仍保留，但 `ENABLE_WORKFLOW_PREFILL = false`，当前不显示预填按钮、不发送 `fields`。
- 不自动提交表单，不执行联查类 `open_related`，不假装已完成真实权限过滤。
- `actionBridge` 清洗 Vue Proxy/ref，注入 `actionId` 后只发送一次 `postMessage`。
- `actionId` 供父页面幂等去重；如果 iGIX 存在多个监听器，父页面仍必须按 `actionId` 去重。

## 门户窗口控制

标题栏右侧使用 Lucide 图标，保留新对话、历史和窗口操作：

- 小窗：显示“切换中窗口”和“切换全屏”。
- 中窗：显示“切换小窗口”和“切换全屏”。
- 全屏：隐藏中窗/全屏按钮，只显示“切换小窗口”和“关闭”。
- 小窗历史弹层相对 Header 定位，避免被容器裁切。

窗口状态由父页面通过 `IGIX_ASSISTANT_WINDOW_STATE` 回传。独立访问时窗口指令会被忽略，不影响聊天功能。

## 当前技术边界

- 前端目前仍使用 `VITE_POLICY_DIFY_*`、`VITE_OFFICE_DIFY_*` 直连 Dify，生产环境存在 Key 暴露风险。
- AI Gateway 已实现健康检查、制度问答代理、动作校验和审计接口，但尚未被前端调用。
- 历史记录仅在当前浏览器保存，不跨设备，也不能作为操作审计。
- `IGIX_AI_ACTION` 当前 targetOrigin 为 `*`；窗口控制协议已限制到父页面 origin。
- 前端未监听动作成功/失败回执，发送成功只代表消息已交给父窗口。

## 关键文件

- `src/App.vue`：主交互、意图路由、历史、流程卡片、窗口按钮。
- `src/services/chatApi.js`：Dify blocking、streaming 和 Mock。
- `src/config/workflowActions.js`：流程映射、状态和匹配规则。
- `src/utils/actionBridge.js`：`IGIX_AI_ACTION` payload 清洗与发送。
- `src/utils/igixAssistantWindow.js`：iframe 窗口控制协议。
- `src/utils/igixUser.js`：当前用户读取和字段白名单。
- `src/utils/conversationStorage.js`：localStorage 历史。
- `ai-gateway/`：Spring Boot AI Gateway。

## 后续优先级

1. 在真实 iGIX 环境逐项验证 `pending` 入口，验证通过后再改为 `verified`。
2. iGIX 监听器按 `payload.actionId` 实现幂等消费并返回执行回执。

5. 接入真实用户权限校验和动作审计。
6. 字段预填如需恢复，应单独验证字段标签、控件类型和失败回滚，仍禁止自动提交。
