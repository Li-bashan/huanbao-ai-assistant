更新时间：2026-09-02

## 项目定位

环宝 AI 智能助手是嵌入 iGIX 企业门户右侧区域的 Vue 前端，不是独立后台，也不负责绕过门户权限直接操作业务系统。

## 当前完成情况

| 模块 | 当前状态 |
|---|---|
| 制度问答 | 页面当前调用 Gateway `/api/ai/master/chat` 的 streaming；兼容层保留制度 blocking 代理。生产部署、真实 Dify 绑定和引用回归待验收。 |
| 办公智能 | 页面当前调用 Gateway `/api/ai/master/chat` 的 streaming，前端处理 `<think>`。生产部署和 Agent 发布状态待验收。 |
| 流程助手 | 前端规则和动作卡片；不接 Dify。当前只有采购请示单为 `verified`。 |
| 智能问数 | `/api/ai/data-query/access` + `/api/ai/data-query/chat`；Gateway 负责签名身份、服务端授权、会话映射、Dify SSE 和审计代码。有效用户端到端未验收。 |
| iGIX 动作 | `IGIX_AI_ACTION`，payload 清洗并注入唯一 `actionId`；父页面需幂等消费。 |
| 窗口控制 | `IGIX_ASSISTANT_WINDOW` / `IGIX_ASSISTANT_WINDOW_STATE`，支持小窗、中窗、全屏、关闭；独立访问时协议降级。 |
| 能力入口 | 四项能力 + 智能自适应，菜单来自 `assistantModes`；自动意图路由仍保留。 |
| 历史和导出 | localStorage 搜索、筛选、恢复、删除、清空；支持复制、Markdown、Word/HTML，问数明细支持 CSV。 |
| 智能填单 | 设计和基础桥接文件存在；`ENABLE_WORKFLOW_PREFILL = false`，当前不发送字段、不自动提交。 |

## 当前流程助手边界

- 唯一开放执行入口：采购请示单 `CGQSD` / `9744034a-7fcc-4510-97fa-f563aecd26e6`。
- `pending` 或 `unsupported` 入口只展示状态，不发送动作。
- `open_form_prefill` 在当前试点版本只打开表单，不携带 `fields`。
- 不自动提交表单，不执行 `open_related`，不假装已完成真实权限过滤。
- 父页面必须按 `actionId` 去重，并自行校验 iGIX 权限。

## 当前技术边界

- 当前代码 `App.vue` 对制度和办公调用统一 Master Gateway；`src/services/chatApi.js` 仍保留 `/policy` blocking 和 `/office` streaming 兼容分发。Master 相关 Java 类和配置已提交，生产服务器部署状态待确认。
- 智能问数生产默认要求 `DATA_QUERY_IDENTITY_MODE=SIGNED_HEADER`。`BODY_TRIAL` 默认关闭，不能当生产认证。
- 浏览器提交的 `untrustedClientContext` 不能覆盖签名身份；Gateway 按租户、用户查询 `ai_data_query_user`，并保存 opaque conversation handle 到 `ai_conversation_mapping`。
- 目标 Dify 草稿的应用 ID、发布版本和协议在文档中存在冲突；本次未拿到足够登录态证据确认 Gateway 的 `DIFY_DATA_QUERY_API_KEY` 实际对应哪个应用。详见[系统抓取与文档同步报告](./系统抓取与文档同步报告-2026-09-02.md)。
- 审计表 DDL 和 Repository 存在，但动作前端未调用审计接口；线上动作审计当前可见 0 条。
- `IGIX_AI_ACTION` 已使用解析后的目标 Origin，但父页面和生产配置仍需收口；前端没有基于 actionId 的重复点击集合。
- 历史记录只在当前浏览器保存，不能替代服务端审计。
