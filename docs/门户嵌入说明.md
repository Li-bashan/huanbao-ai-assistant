# 门户嵌入说明

## 当前嵌入目标

环宝 AI 智能助手目标嵌入企业门户右侧区域，作为门户中的 AI 助手面板。

## 右侧助手面板

当前前端保持：

- `width: 100%`
- `height: 100vh`
- Header / ChatBody / Footer 三段式。
- 不使用 `position: fixed` 作为全局浮层。

## iframe 嵌入方式

示例：

```html
<iframe
  src="http://192.168.245.138:8090"
  style="width: 100%; height: 100%; border: 0;"
></iframe>
```

## 门户悬浮入口

门户可提供右侧入口按钮，点击后显示 iframe 面板。助手内部不负责门户级悬浮入口。

## 窗口尺寸

建议右侧面板宽度 420px - 560px。全屏预览时内容有最大宽度限制。

## 最大化

Header 已有最大化按钮视觉入口，后续可通过 postMessage 通知父页面放大 iframe。

## postMessage 规划

建议协议：

```js
window.parent.postMessage({
  source: 'huanbao-ai-assistant',
  type: 'OPEN_FORM',
  payload: {
    formCode: '待补充',
    workflowName: '采购请示单'
  }
}, '*')
```

## ticket 免登方案

后续由门户在 iframe URL 或 postMessage 中传入短期 ticket。助手或后端代理用 ticket 换取用户信息。

## 用户身份传递

建议传递：

- userId
- userName
- orgId
- roles
- ticket

不要在 URL 中长期暴露敏感 token。

## 权限校验

打开表单、菜单、待办前必须由门户 / iGIX / 后端校验权限。Dify 不应直接执行业务动作。

## 后续接 iGIX 表单打开

流程助手动作按钮应发送动作事件，由父页面或后端工具执行：

- 打开菜单。
- 打开表单。
- 预填字段。
- 跳转待办。

## 安全注意事项

- 限制 postMessage origin。
- 不让 Dify 直接调用业务系统。
- 服务端记录动作审计。
