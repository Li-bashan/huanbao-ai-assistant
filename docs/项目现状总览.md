## 当前权威快照（2026-09-15）

### 一句话结论

项目仍是 Vue 3 + Vite 的 iGIX 企业门户右侧助手，包含制度问答、办公智能、流程助手和智能问数四项能力。智能问数当前已经由 AI Gateway 转发到独立 `huanbao-dataquery:8089` 服务执行，不依赖 Dify 查询工作流；制度、办公和 Master 的 Dify 代理配置仍存在，整体去 Dify 化尚未施工。

### 已观察的页面症状及代码根因

| 页面现象 | 代码事实 | 当前判断与后续要求 |
|---|---|---|
| “暂未获取到该维度的结构化分析数据，建议尝试按时间趋势或组织排名提问。” | `DataQueryResult.vue` 只有在 `protocolVersion=2.0` 且 `protocolValid=true` 时才进入结构化视图，否则由 `ProtocolFallbackView.vue` 展示这句本地兜底文案。 | 这句话不等于数据库没有数据，更不等于只能问趋势/排名；它首先说明前端没有收到可通过校验的结构化结果。必须检查 SSE 的 `analysis_result`、协议字段、Gateway 转发和前端发布版本。 |
| “智能问数执行失败，请稍后重试。” | `DataQueryExecutionController` 捕获非指标不支持类异常时发送 `QUERY_EXECUTION_FAILED`，前端只显示通用错误；真实异常只在 dataquery 服务日志中按 `requestId` 记录。 | 截图本身不能证明是数据库、模型、权限还是网络故障。必须用 `requestId` 关联 Gateway 和 8089 日志，并把失败阶段、机器码和可行动原因返回前端，不能把所有异常压成一句话。 |
| “暂未识别出可查询的生产指标，请换用指标库中的名称重试。” | 指标/意图分类无法解析到受控指标时发送 `QUERY_NOT_SUPPORTED`；问题可能是推荐词、别名、时间/组织组合没有进入语义字典或规则。 | 应补齐指标别名、推荐题目和 golden case 的契约测试，不得让模型自由生成指标名后直接查库。 |
| 推荐问题点击后也执行失败 | `PromptStarters` 只是把题目交给 `App.vue -> sendMessage`；推荐问题和手工输入共用同一 Gateway、身份、会话、问数执行和协议链路，复合题目才额外指定 data-query + office 模式。 | 如果多条推荐问题一起失败，优先查共享链路、身份授权、dataquery 版本、语义覆盖和协议，而不是单独修按钮。每条推荐题目都必须有 `id -> prompt -> expected plan -> expected status` 回归记录。 |
