## 本次抓取摘要

- 前端：Vue 3 + Vite，支持独立访问，也设计为 iGIX 门户 iframe 右侧助手。
- 当前工作区页面链路：智能问数走 `/api/ai/data-query/chat`；制度问答和办公智能的未提交改动走 `/api/ai/master/chat`；流程助手走前端规则和动作卡片。
- Gateway 线上只读探测：`GET /api/ai/health` 返回 200、`UP`、版本 `0.1.0`；动作审计查询 200 且当前总数为 0；未授权人员接口 401。
- 本地验证：`npm run build` 和 `ai-gateway/mvn clean test -q` 通过；独立浏览器没有 iGIX 用户身份，智能问数按预期阻断。
- 流程助手：当前只有采购请示单为 `verified`；本地浏览器已验证卡片识别和一次 `IGIX_AI_ACTION` 发送。
- iGIX 动作：通过 `IGIX_AI_ACTION` 发送，payload 发送前清洗并注入唯一 `actionId`，目标 Origin 由配置、referrer 或默认门户 Origin 解析。
- 窗口控制：通过 `IGIX_ASSISTANT_WINDOW` 与父页面协作，支持小窗、中窗、全屏和关闭；独立访问时降级。
- 历史：浏览器 localStorage，最多 50 条，支持搜索、分类、删除和清空。
- 智能填单：仍是设计和桥接方案，`ENABLE_WORKFLOW_PREFILL = false`，当前不发送 `fields`。
- Dify：线上公开 Web App 可达，但本次没有执行真实业务查询；Dify 多个应用、草稿和升级报告之间存在版本/应用 ID 冲突，未取得足够证据确认 Gateway 实际绑定的 Dify 资产。
