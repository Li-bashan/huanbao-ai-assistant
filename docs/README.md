# 文档索引

更新时间：2026-07-22

本目录记录环宝 AI 智能助手当前实现、接入协议、部署和验收方式。代码是最终事实来源；功能或协议变化时，应同步更新本目录相关文档。

## 当前状态摘要

- 前端：Vue 3 + Vite，作为 iGIX 门户 iframe 内的右侧助手运行。
- 制度问答：前端直连 Dify，blocking 返回并展示引用来源。
- 办公智能：前端直连 Dify Agent，SSE streaming 输出并过滤 `<think>`。
- 流程助手：前端规则识别和动作卡片，不接 Dify；当前只有采购请示单为 `verified`。
- iGIX 动作：通过 `IGIX_AI_ACTION` 发送，payload 发送前清洗并注入唯一 `actionId`。
- 窗口控制：通过 `IGIX_ASSISTANT_WINDOW` 与父页面协作，支持小窗、中窗、全屏和关闭。
- 历史：浏览器 localStorage，最多 50 条，支持搜索、分类、删除和清空。
- AI Gateway：Spring Boot 服务代码已存在，但当前前端尚未切换到网关。
- 字段预填：代码保留解析能力，`ENABLE_WORKFLOW_PREFILL = false`，当前不发送 `fields`。
