# 部署说明

## 本地开发

```bash
cd ~/company-projects/huanbao-ai-assistant
npm install
npm run dev
```

修改 `.env.local` 后必须重启 `npm run dev`。

## 本地构建

```bash
cd ~/company-projects/huanbao-ai-assistant
npm run build
```

## Git 提交

```bash
git status
git add .
git commit -m "说明"
git push
```

## 服务器拉取

```bash
cd /LBSops/huanbao-ai-assistant
git pull
```

服务器 `git pull` 拉的是远程仓库，不是 Mac 本地代码。如果本地显示领先 `origin/main`，必须先 `git push`。

## 安装依赖

```bash
npm ci
```

## 构建 dist

```bash
npm run build
```

## Nginx reload

```bash
systemctl reload nginx
```

## 完整部署命令

本地：

```bash
cd ~/company-projects/huanbao-ai-assistant
npm run build
git status
git add .
git commit -m "说明"
git push
```

服务器：

```bash
cd /LBSops/huanbao-ai-assistant
git pull
npm ci
npm run build
systemctl reload nginx
```

## 环境变量

`.env.local` 不提交。`.env.example` 可提交。

```env
VITE_DIFY_USER=your-user-id
VITE_USE_DIFY=true
VITE_POLICY_DIFY_API_BASE=http://your-dify-host/v1
VITE_POLICY_DIFY_API_KEY=app-your-policy-key
VITE_OFFICE_DIFY_API_BASE=http://your-dify-host/v1
VITE_OFFICE_DIFY_API_KEY=app-your-office-key
```

## 常见错误排查

- 服务器没有新代码：检查本地是否 `git push`。
- 环境变量不生效：重启 dev 或重新构建。
- 页面缓存：浏览器强刷。
- 确认版本：

```bash
git log --oneline -5
```

- 401：Dify Key 错误。
- Agent blocking 错误：办公智能必须 streaming。
