# 产品功能说明

## 产品定位

环宝 AI 智能助手是企业门户里的统一 AI 助手入口，核心目标是让员工在一个入口完成“查制度、写材料、办流程”。

## 用户场景

- 员工想知道差旅费、报销、公务用车等制度要求。
- 员工需要起草通知、整理会议纪要、生成工作总结。
- 员工不知道采购请示单、合同评审、待办入口在哪里。
- 员工希望 AI 帮助识别需求并自动分发到合适能力。

## 制度问答

制度问答用于查询公司制度知识库。

典型问题：

- 差旅费包括哪些费用？
- 出差住宿费和伙食补助标准是多少？
- 公务用车如何申请？

功能特点：

- Dify blocking 返回。
- 支持 Markdown。
- 展示引用来源。
- 支持展开原文片段。

## 办公智能

办公智能用于处理办公材料。

典型需求：

- 帮我整理一份会议纪要。
- 帮我润色一段事项审批说明。
- 帮我生成一份本周工作总结。

功能特点：

- Dify Agent streaming 输出。
- 自动过滤模型 `<think>` 思考过程。
- 适合通知、公告、汇报、总结、摘要。

## 流程助手

流程助手用于辅助办理业务事项。

当前支持：

- 采购请示单。
- 合同评审流程。
- 我的待办。

当前行为：

- 展示动作卡片。
- 提供“打开、查看说明、预填表单”等演示按钮。
- 不打开真实表单。

## 自动意图识别

用户无需先选模式。系统会根据输入内容自动判断：

- 查制度：进入制度问答。
- 写材料：进入办公智能。
- 办流程：进入流程助手。

示例：

- “给我整理会议纪要：流程、表单、审批节点……”进入办公智能。
- “打开采购请示单”进入流程助手。
- “差旅费包括哪些费用？”进入制度问答。

## 历史会话

历史记录保存在浏览器 localStorage，支持：

- 搜索历史。
- 按制度 / 办公 / 流程筛选。
- 按今天 / 昨天 / 更早分组。
- 删除单条。
- 清空历史。

## 复制和导出

每条 AI 回复支持：

- 复制纯文本。
- 导出 Markdown。
- 导出 Word/HTML。

流程卡片导出会包含事项、操作和字段。

## 最大化 / 右侧面板形态

当前设计是右侧嵌入式面板。Header 保留最大化按钮视觉入口，后续可接门户父页面放大能力。

## 后续功能规划

- 门户悬浮入口。
- postMessage 动作协议。
- iGIX 菜单/表单打开。
- 表单字段预填。
- 服务端历史与审计。
- 用户身份与权限控制。
