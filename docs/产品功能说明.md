# 产品功能说明

更新时间：2026-09-02

## 产品定位

环宝 AI 智能助手是 iGIX 企业门户内的右侧 AI 助手，用一个输入入口承接制度查询、办公材料处理、流程入口定位和生产指标查询。它支持独立开发访问，但用户身份、窗口控制和业务动作需要真实门户父页面配合。

## 用户可见能力

### 制度问答

- 适用于制度、标准、报销和审批规则查询。
- 当前工作区页面通过 Gateway 的 Master streaming 入口；兼容层保留制度 blocking 代理。
- 支持 Markdown、引用来源和原文片段展开；真实引用回归待目标 Dify 绑定确认。

### 办公智能

- 适用于通知、会议纪要、总结、润色和摘要。
- 当前工作区页面通过 Gateway Master SSE，页面实时追加内容并过滤 `<think>`。
- 统一 Master 相关前后端代码已提交并与 origin/main 同步，但生产服务器是否已拉取、重载和完成 Dify 回归仍待确认。

### 流程助手

- 通过前端规则识别具体入口或流程清单问题，不调用 Dify。
- 支持采购、运维、科技、综合模块的已配置入口展示。
- 状态分为已开放 `verified`、待实测 `pending`、暂不支持 `unsupported`。
- 当前只有采购请示单可点击打开；点击后向 iGIX 父页面发送 `IGIX_AI_ACTION`。
- 字段预填关闭，不自动填表、不自动提交；真实权限以 iGIX 为准。

### 智能问数

- 仅支持生产指标数据查询，页面通过 Gateway `/api/ai/data-query/chat` 访问 Dify streaming。
- Gateway 默认要求门户签名身份，并按 `tenantId + userId` 查询服务端 `ai_data_query_user`；浏览器提交的用户字段不具备授权效力。
- 结果协议支持 v2 结构化摘要、指标卡、表格、图表、洞察、数据说明、澄清候选和追问；旧文本可降级展示。
- 前端不重新计算或排序业务数据。是否真实返回 v2、权限是否进入 SQL 执行边界，必须在目标 Dify/Kingbase 环境确认。

## 自动意图路由

`intentRouter` 根据关键词和当前模式在制度、办公、流程、问数之间分发；流程动作优先，办公材料中的“流程”“表单”不应误判为流程入口。

- `差旅费包括哪些费用？` -> 制度问答。
- `帮我写一份关于智慧办公系统临时维护的通知` -> 办公智能。
- `打开采购请示单` -> 流程助手。
- `给我整理会议纪要：流程、表单、审批节点……` -> 办公智能。
- `查询本月垃圾处理量` -> 智能问数，但必须先通过门户身份和服务端开放范围检查。

## 标题栏与窗口

标题栏展示“智能能力 · 4项”和智能自适应/当前能力选择器，保留新对话、历史记录、小窗/中窗、全屏和关闭。手动选择会切换当前模式，但智能自适应仍可自动路由；窗口尺寸由门户父页面控制。

## 历史会话

历史保存在浏览器 localStorage，最多 50 条，支持搜索、按四种模式筛选、按日期分组、恢复、删除和清空。loading 或 streaming 中间状态不入库；Dify 会话句柄按模式分开，不能把历史当作服务端审计。

## 复制和导出

完整 AI 回复支持复制纯文本、导出 Markdown 和导出 Word/HTML；智能问数结构化明细支持复制和 CSV 导出。流程卡片恢复时只保留展示信息，不直接执行旧 payload。

## 当前限制

- 代码已完成 Git push；服务器 pull、Nginx reload、Dify 绑定和生产回归仍需目标环境确认。
- Dify 资产文档存在多个应用 ID、工作流版本和协议记录，本次未确认 Gateway 实际绑定的 App/发布版本。
- 本次未执行真实 Kingbase 业务查询，数据库表结构和业务数字不能用历史报告替代。
- 独立访问无法取得 iGIX 用户和签名身份，智能问数会停在开放范围校验。
- 流程助手未完成真实权限过滤、执行回执和自动审计；只有采购请示单已验证。
- 字段预填和自动提交均未开放。
