# 产品功能说明

更新时间：2026-08-31

## 产品定位

环宝 AI 智能助手是 iGIX 企业门户内的右侧 AI 助手，通过一个输入入口承接制度查询、办公材料处理、流程入口定位和生产指标数据查询。

四项智能能力会在标题栏能力菜单中显式展示，但能力不是互相隔离的工作区。用户可以直接输入，系统会在明确跨域时自动切换并保留本地对话上下文。

## 用户可见能力

### 制度问答

- 适用于制度、标准、报销和审批规则查询。
- 使用 Dify blocking，一次返回完整答案。
- 支持 Markdown、引用来源和原文片段展开。
- 知识库无有效依据时展示统一无命中提示。

### 办公智能

- 适用于通知、会议纪要、总结、润色和摘要。
- 使用 Dify Agent streaming，页面实时追加内容。
- 模型输出中的 `<think>` 不展示，也不保存到历史。

### 流程助手

- 通过前端规则识别具体入口或流程清单问题，不调用 Dify。
- 支持按采购、运维、科技、综合模块展示已配置入口。
- 入口状态分为已开放 `verified`、待实测 `pending`、暂不支持 `unsupported`。
- 当前仅采购请示单可点击打开；点击后向 iGIX 父页面发送动作。
- 当前字段预填关闭，不自动填表、不自动提交。
- “我的权限”类查询只展示配置状态，真实权限以 iGIX 为准。

### 智能问数

- 仅支持生产指标数据查询，由 Dify Workflow 返回真实结果，Gateway 负责安全代理。
- 环宝调用 `/api/ai/data-query/chat`；前端不持有智能问数 Dify API Key，也不接触 SQL 或数据库连接信息。
- 结果按 v2 协议展示核心摘要、指标卡、表格、图表、洞察、数据说明和追问入口，技术细节默认折叠。
- 支持排名、趋势、比较、同比排名、异常和下钻等协议类型；前端不重新计算或重新排序业务数据。
- 组织/指标无法唯一确定时显示候选卡片，点击后继续原 conversation；连续追问不要求重复时间、指标和组织。

## 自动意图路由

四个能力入口在助手内显式展示。用户直接输入内容后，`intentRouter` 自动选择制度问答、办公智能、流程助手或智能问数；没有明确跨域意图时继承当前模式。

回归示例：

- `差旅费包括哪些费用？` -> 制度问答。
- `帮我写一份关于智慧办公系统临时维护的通知` -> 办公智能。
- `打开采购请示单` -> 流程助手。
- `给我整理会议纪要：流程、表单、审批节点……` -> 办公智能，不能因“流程”误判。
- `查询本月垃圾处理量` -> 智能问数，仅在命中生产指标词时路由。

## 标题栏与窗口

标题栏左侧保留当前助手名称和在线状态，中间显示来自 `assistantModes` 的“智能能力 · N项”和当前能力选择器，右侧提供：

- 制度问答、办公智能、流程助手、智能问数四项能力的下拉选择。
- 新对话。
- 历史记录。
- 小窗与中窗切换。
- 全屏切换。
- 关闭助手。

全屏状态只显示“切换小窗口”和“关闭”；窗口尺寸由门户父页面控制。独立打开前端时，窗口指令不会改变浏览器窗口。

能力选择器只切换当前处理能力，不清空当前聊天、不直接调用 Dify，也不会关闭自动意图路由。用户直接输入时，系统仍会在明确跨域意图下自动切换当前能力；没有明确跨域意图时优先继承当前对话语境。小窗空间不足时隐藏能力数量说明，但保留当前能力选择器。

## 历史会话

历史保存在浏览器 localStorage，最多 50 条，支持搜索、按四种模式筛选、按日期分组、恢复、删除和清空。loading 或 streaming 中间状态不会入库。跨模块对话仍保存为一条会话，各 Dify 应用的 conversationId 独立保存。

历史弹层位于标题栏下方，在小窗模式使用容器内自适应宽度，避免被面板裁切。

## 复制和导出

完整 AI 回复支持复制纯文本、导出 Markdown 和导出 Word/HTML。流程卡片随会话保存，但恢复历史时只保留可展示信息，不直接恢复可执行 payload。

## 当前限制

- 智能问数、制度问答和办公智能已切换到 AI Gateway；生产 Dify Key 只配置在 Gateway，Dify 发布和目标环境联调仍需单独验收。
- 历史不跨浏览器或设备。
- 流程助手未完成真实权限过滤和执行回执。
- 只有采购请示单入口已开放。
- 字段预填和自动提交均未开放。
